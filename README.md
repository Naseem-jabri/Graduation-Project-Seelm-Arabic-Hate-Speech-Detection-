# Seelm

## Overview

Seelm is a graduation project that addresses the increasing spread of hate speech and offensive content on social media and its negative impact on online safety and digital communication.

While regulations exist, automated solutions are essential to handle the scale of user-generated content. Most existing hate speech detection systems primarily focus on the English language, leaving Arabic significantly underrepresented despite being one of the most widely used languages online. This challenge is further complicated by the linguistic complexity of Arabic, including its rich morphology, complex grammar, and the widespread use of dialects in everyday communication.

## Features

- Arabic hate speech detection using Machine Learning and Natural Language Processing (NLP).
- Real-time text analysis through a custom smart keyboard.
- Instant alerts when potentially offensive language is detected.
- Mobile application with separate interfaces for children and parents.
- Supports safer online communication while promoting responsible digital behavior.
- Privacy-focused system design.

## Dataset

The project involved the manual reclassification and refinement of an existing dataset containing more than **25,000 Arabic tweets**, improving label consistency and overall dataset reliability for model training.

## Technologies

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Transformers
- Flutter
- Firebase

## System Workflow

1. The user types text using the custom keyboard.
2. The text is analyzed in real time by the trained hate speech detection model.
3. If offensive content is detected, the system immediately notifies the user.
4. The mobile application provides monitoring and awareness features for both parents and children.

## Objective

The goal of Seelm is to provide an intelligent Arabic hate speech detection system that improves online safety, encourages respectful digital communication, and addresses the lack of Arabic-focused moderation tools.
